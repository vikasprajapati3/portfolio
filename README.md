# Vikas Prajapati — Portfolio

Personal portfolio built with React, Vite, and Tailwind CSS.

🔗 **Live:** [vikasprajapati3.github.io/portfolio](https://vikasprajapati3.github.io/portfolio)

## Stack

- React 18
- Vite 5
- Tailwind CSS 3
- Formspree (contact form)

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
